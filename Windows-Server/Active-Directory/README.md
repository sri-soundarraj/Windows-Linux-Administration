# Active Directory Administration

## Objective

Configure and manage a Windows Server Active Directory environment.

## Topics Covered

- Active Directory Domain Services (AD DS)
- Domain Controller
- Organizational Units
- Users and Groups
- Domain Joining
- Password Policies
- Account Lockout
- User Permissions

## Lab Environment

- Windows Server
- Windows 10/11 Client
- Active Directory Domain Services
- DNS

## Practical Tasks

1. Install AD DS
2. Promote Windows Server to Domain Controller
3. Create a domain
4. Create Organizational Units
5. Create users and groups
6. Join Windows client to the domain
7. Test domain authentication

## Troubleshooting

- Domain login failure
- DNS resolution problems
- Client unable to join domain
- User authentication issues
